## Lancer le projet localement

Ce portfolio est un site statique. Clonez le dépôt puis ouvrez `index.html` dans votre navigateur :

```bash
git clone git@github.com:BEGUIL/Portfolio-BEGUILZONE.git
cd Portfolio-BEGUILZONE
```

Vous pouvez également utiliser une extension comme **Live Server** dans Visual Studio Code.
